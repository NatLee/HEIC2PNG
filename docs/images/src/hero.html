heic2png

iPhone HEIC photos to PNG or JPEG, from the shell or from Python.

$pip install heic2png
HEIC photo
photo.heic
straight off an iPhone or iPad
Command line or Python
$ heic2png -i photo.heic
or HEIC2PNG("photo.heic").save()
pipes: heic2png < a.heic > a.png
PNG -q 100
photo.png
every color, transparency kept
JPEG -f jpg
photo.jpg
